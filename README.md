## Deskripsi singkat mengenai repository

Repository adalah tempat dimana kita bisa menyimpan code, files, dan revision's history. Repositories juga mendukung collaborators artinya kita bisa bekerja sama di satu repositories.

## Dokumentasi singkat

Pada materi pertama kita diberikan materi prompting, cara prompting yang baik dan berbagai taktik yang bisa digunakan untuk prompt, contoh prompt yang baik yaitu menerapkan Role, Task, Context, dan format agar hasil output yang didapat sesuai dengan yang diinginkan.

Lalu setelah materi Prompt, kita di berikan materi Git dan GitHub, disini dijelaskan apa itu Git dan sejarahnya lalu workflow dari git yang memiliki 3 states, yaitu Checkout atau cloning repo dari databases seperti GitHub ke local computer, lalu Staging adalah fase dimana sebuah file sudah di track perubahannya untuk dicommit, lalu commit dimana kita mengambil file yang sudah di track tersebut lalu menyimpan snapshot di directory Git lokal komputer.

Lalu dilanjut dengan mengimplementasian command-command yang ada pada Git, membuat repo, melihat status dari file, membuat ssh key supaya tidak perlu melakukan autentikasi setiap kali ingin melakukan pekerjaan di suatu repository.

### Poin yang saya pelajari di workshop 

- Mempelajari prompt yang baik.
- Mempelajari apa itu Git, dan bagaimana alur kerjanya.
- Memanfaatkan AI sebaik mungkin untuk mendapatkan output yang memuaskan.

### Pendapat pribadi tentang Day 1 Proyek Workshop

Belajar banyak dari workshop kali ini, sekarang tau perbedaan dari Git dan Github dan cara Prompt yang baik dan benar, akan lebih seru lagi kalau pembahasan tentang Git diperdalam.
